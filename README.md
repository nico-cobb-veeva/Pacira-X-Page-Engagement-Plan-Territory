# myinsights-custom-boilerplate-vue3

## Introduction
This is a Vue 3 boilerplate for fully custom MyInsights / X-Pages applications. It uses Pinia for state management and Vue Router for navigation.

## Project setup
To get started, clone the repository and install dependencies:
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```

## Features
- Modular components
- Internationalization (i18n) support

## Technologies Used
- **Vue 3** - Front-end framework
- **Pinia** - State management
- **Vue Router** - Routing
- **Moment.js** - Date manipulation
- **Bootstrap** - UI components
